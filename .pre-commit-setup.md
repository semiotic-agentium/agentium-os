# Pre-commit Hook Setup

## Installation

1. Install pre-commit framework:
   ```bash
   pip install pre-commit
   # or
   brew install pre-commit
   ```

2. Install the git hooks:
   ```bash
   pre-commit install
   ```

3. Install Rust tools if not already installed:
   ```bash
   rustup component add rustfmt
   rustup component add clippy
   cargo install cargo-audit
   cargo install cargo-deny
   cargo install cargo-machete
   cargo install cargo-outdated
   # Initialize cargo-deny configuration
   cargo deny init
   ```

## Usage

- Hooks run automatically on `git commit`
- Run manually on all files: `pre-commit run --all-files`
- Run on staged files only: `pre-commit run`
- Skip hooks: `git commit --no-verify` (not recommended)

## Hooks Included

1. **File checks**: trailing whitespace, end-of-file, YAML/JSON/TOML validation, large files, merge conflicts
2. **rustfmt**: Formatting check (doesn't auto-format, just checks)
3. **clippy**: Linting with warnings as errors (`-D warnings`)
4. **cargo-audit**: Security vulnerability scanning (denies warnings)
5. **cargo-deny**: License checking, banned crates, and additional security checks
6. **cargo-machete**: Find unused dependencies in Cargo.toml files
7. **cargo-outdated**: Check for outdated dependencies (exits with code 1 if outdated found)
8. **typos**: Spell checking for code (excludes generated files)
9. **cargo-check**: Basic compilation check on all targets

## Additional Recommended Tools (Not in pre-commit)

- **cargo-udeps**: Find unused dependencies (`cargo install cargo-udeps`) - alternative to cargo-machete
- **cargo-geiger**: Security audit counting unsafe usage (`cargo install cargo-geiger`)
