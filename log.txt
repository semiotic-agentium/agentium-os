commit d25dca157e4e9ecf369297925fb11471f339d2ee
Author: Ryan Roberts <ryan@semiotic.ai>

    fix(baml): inject fnox-resolved secrets as env_vars into BamlRuntime
    
    BAML schemas reference API keys as `api_key env.OPENROUTER_API_KEY`.
    BAML resolves these from the env_vars HashMap passed to
    BamlRuntime::from_directory. We were passing an empty HashMap, so BAML
    fell back to std::env::var() — which is empty in CI (secrets live in
    fnox.toml, not environment variables).
    
    Fix: before loading the schema, resolve all known LLM secret keys from
    the fnox resolver and pass them as env_vars. BAML's env.X resolution
    then finds the values without touching the process environment.
    
    Result: eliminates 401 "Missing Authentication header" errors in CI,
    which were causing 3-retry storms on every LLM call and 60-180s
    coordinator/notion test timeouts.
    
    Made-with: Cursor
