# baml-rt-tools

Tool system primitives for the BAML Runtime workspace.

## Responsibilities

- `BamlTool` trait and metadata contracts.
- Tool registry and executor abstractions.
- Session FSM primitives for host tool execution.

## TypeScript bindings

`crates/baml-rt-tools/bindings/` is generated by `ts-rs` from the Rust types in this crate.
These files are checked in; if Rust structs/enums change, re-running a build/test for this
crate will update the bindings and the diffs should be committed.
